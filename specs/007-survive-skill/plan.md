# Implementation Plan: Survive Skill

**Branch**: `007-survive-skill` | **Date**: 2026-05-17 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `/specs/007-survive-skill/spec.md`

## Summary

Add a new `SURVIVE` skill kind that intercepts the first fatal blow a card receives, setting HP to 1 instead of 0. Interception is implemented inside `FightingCard.applyFinalDamage()` (single choke-point for all damage paths). `ActionStage` fires a `'survived'` event via the existing `launchSkills` mechanism, allowing standard `AlterationSkill` entries to handle post-survival buffs — no new method on `FightingCard`, no new buff machinery. The surviving card emits a new `survived` step in the battle log.

### Step 3 — Domain: `SurviveSkill`

**File**: `src/fight/core/cards/skills/survive.ts` (new)

```typescript
export class SurviveSkill {
  public readonly name: string;
  private consumed = false;

  constructor(name: string) {
    this.name = name;
  }

  tryConsume(): boolean {
    if (this.consumed) return false;
    this.consumed = true;
    return true;
  }
}
```

No `Alteration[]`. No `launchBuffs()`. Single responsibility: intercept a fatal blow.

### Step 5 — Domain: `FightingCard` integration

**File**: `src/fight/core/cards/fighting-card.ts`

1. Add `private surviveSkill: SurviveSkill | null = null` field.
2. Add `survive?: SurviveSkill` to the `skills` constructor parameter.
3. Assign `this.surviveSkill = skills.survive ?? null` in the constructor.
4. Modify `applyFinalDamage()`:

```typescript
public applyFinalDamage(damage: number): FinalDamageResult {
  let causedDamages = damage;
  // ... existing freeze/stunt amplification ...

  const shieldAbsorbed = this.absorbWithShield(causedDamages);
  let damageToHealth = causedDamages - shieldAbsorbed;

  // Survive interception: cap damage so health stays at 1
  if (this.actualHealth - damageToHealth <= 0 && this.surviveSkill?.tryConsume()) {
    damageToHealth = this.actualHealth - 1;
    this.receivedDamages += damageToHealth;
    return {
      damageToHealth,
      shieldAbsorbed,
      survived: true,
      survivedSkillName: this.surviveSkill.name,
    };
  }

  this.receivedDamages += damageToHealth;
  return { damageToHealth, shieldAbsorbed };
}
```

*Note*: `this.surviveSkill.name` is safe here because `tryConsume()` returning `true` implies `this.surviveSkill` is non-null.

### Step 6 — Domain: `ActionStage` — handle survival

**File**: `src/fight/core/card-action/action-stage.ts`

In `handleAttackResult`, after `report.attack.damages.push(...)` for each result, add the survived branch **before** the existing dead/alive check:

```typescript
if (damageDealt.survived) {
  report.statusChanges.push({
    kind: StepKind.Survived,
    name: damageDealt.survivedSkillName,
    card: defensiveCard.identityInfo,
  });
  const survivedSkillResults = defensiveCard.launchSkills(
    'survived',
    this.getFightingContext(defensiveCard),
  );
  report.statusChanges.push(
    ...skillResultsToSteps(defensiveCard, survivedSkillResults),
  );
}
```

When `survived: true`, the card is alive at 1 HP — the existing `isDead()` check returns `false`, so no death handling is triggered.

**File**: `src/fight/http-api/fight.controller.ts`

```typescript

    simpleAttack: attackSkill,
```
